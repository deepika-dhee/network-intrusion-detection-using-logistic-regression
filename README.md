# Network Intrusion Detection Using Logistic Regression

## Project Overview
This project uses Logistic Regression to detect network intrusions by classifying network traffic as normal or malicious.

## Dataset
- Dataset: Synthetic Network Intrusion Dataset
- Target column: `intrusion`

## Implementation Steps
1. Load and explore the dataset.
2. Separate input features and target variable.
3. Encode categorical features using One-Hot Encoding.
4. Split the dataset into training, validation, and testing sets.
5. Standardize numerical features using StandardScaler.
6. Train a Logistic Regression model.
7. Evaluate model performance.
